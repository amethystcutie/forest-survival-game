## Controls
Controls are now visible in-game (press H to toggle)
**As of v0.2-alpha:**
	WASD to move
	Space to jump
	Shift to run
	1-8 or scroll to change item
	E to open/close inventory
	Left click to attack/swing
	Right click to use item
	+/- to zoom
	Esc to quit game
	H to toggle these hints
